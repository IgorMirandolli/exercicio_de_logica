# Exercícios de Lógica Proposicional

Este repositório reúne resoluções de exercícios de **Lógica Proposicional**, com foco em formalização de sentenças, verificação de validade de argumentos, fórmulas bem formadas e provas por regras do cálculo proposicional.

O material foi organizado em arquivos separados para facilitar a leitura, o estudo e a revisão dos conteúdos.

## Objetivo

O objetivo deste repositório é servir como material de apoio para o estudo de lógica proposicional, apresentando resoluções organizadas e justificadas de exercícios.

Cada argumento é tratado com atenção à sua estrutura lógica, distinguindo quando uma conclusão realmente decorre das premissas e quando é possível construir um contraexemplo.

---

## Como Estudar

Uma boa forma de usar este material é:

1. Ler primeiro o enunciado do exercício.
2. Tentar formalizar por conta própria.
3. Comparar com a resolução apresentada.
4. Verificar se o argumento é válido ou inválido.
5. Revisar a prova ou o contraexemplo usado.

---

## Observações

Algumas frases da linguagem natural podem ter mais de uma interpretação lógica possível. Quando necessário, foram adotadas interpretações padrão da lógica proposicional, como:

- “A, a menos que B” interpretado como `¬B → A`.
- “A somente se B” interpretado como `A → B`.
- “A se e somente se B” interpretado como `A ↔ B`.
